🌟 Project Showcase – Stopwatch Web App ⏱️

A modern, interactive Stopwatch Web Application designed with a focus on clean UI, smooth animations, and user experience. This project demonstrates strong fundamentals in frontend development using HTML, CSS, and JavaScript.

✨ Key Features

🔹 Sleek & Modern UI
Animated gradient background for a visually appealing interface

🔹 Circular Timer with Animated Progress
Conic-gradient–based circular progress indicator that updates in real time

🔹 Core Stopwatch Controls

▶️ Start

⏸️ Pause

🔄 Reset

🏁 Lap tracking

🔹 Lap Time Recorder
Smooth auto-scrolling lap list for better readability

🔹 Dark / Light Mode Toggle
User-friendly theme switching for better accessibility

🔹 Fully Responsive Design
Optimized for both mobile and desktop devices

🔹 Real-Time Sound Feedback
Audio cues for start, pause, lap, and reset actions

🔹 Interactive UX Enhancements
Hover animations on the title and controls for a dynamic feel

🔹 Clean & Modular Code Structure
Well-organized project with separate:

HTML – structure

CSS – styling & animations

JavaScript – stopwatch logic

🛠️ Tech Stack

HTML5

CSS3

JavaScript (ES6)

🎯 Project Purpose

This project was built to:

Strengthen JavaScript timing and event-handling concepts

Practice advanced CSS animations and gradients

Improve UI/UX design skills

Create a real-world, interactive web application
